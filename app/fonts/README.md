# fonts

`long-cang-wang-thin.woff2` holds a single glyph: 王, taken from Long Cang and
eroded to a lighter stroke. Long Cang draws that character with a 0.079em stroke
where 家悦 beside it sit at 0.049em, and the family ships only one weight, so
there is no lighter cut to switch to. `scripts/thin-wang.py` regenerates it from
the upstream font and prints the before/after measurements.
